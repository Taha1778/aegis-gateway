Known boundaries

Encoded, multilingual, and novel attacks can evade the detector. Quoted attack examples can trigger false positives. Binary files and malware scanning are not supported. An application must enforce tool decisions and prevent direct provider bypass.

Connection settings

Local demo needs no keys. Protected instances require separate application and administrator credentials.

Keys are kept in memory only and cleared on reload.
